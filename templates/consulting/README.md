# Consulting starter

Eight slides: cover, executive summary, storyline, hypothesis tree, ghost chart,
2x2, plan, next steps. Adapted from [StrategyU's consulting templates](https://strategyu.co/strategy-consulting-powerpoint-templates/).

| File | Edit here |
|---|---|
| `content.js` | Slides/notes: `ct(key, cat, title, extra)` references `CT[key]` |
| `pitches.js` | Versions and slide order |
| `ct-slides.js` | Converted editable shapes; engine uses the `pptx` layout |

Converted with `tools/pptx2native.py`. Engine fonts can change line breaks; titles
retain 26 pt and tables use engine styling. The 2x2 has a text-size advisory.
